# Bondbuilder pilot runbook v0.1

Authority: [provisional standard](bondbuilder-classification-standard.v0.1.md). No adapter or production writes.

1. Source preparation: inspect the report's leads, exact local manufacturer/formula sources and primary evidence. Record source scope, access failures, dates, identity conflicts and protocol requirements. This stage is unblinded and is not a classification lane.
2. Freeze: write versioned anonymous formula and named evidence packets, cohort manifest and SHA-256 receipt for the exact standard/lexicon and packets. Never pretend a foreign page verifies a local pack; unresolved rows are holds.
3. Independent formula lanes: fresh researchers receive only the exact standard and anonymous packet. No web, names, previous grades, report, plan, peer outputs or expected answers. Each returns marker/architecture candidates, confidence, limitations and a read/seal/recognition-incident receipt. Freeze both before unblinding.
4. Independent evidence lanes: give the same named evidence packet to those researchers, still without peer output. Return boundary, trust or hold, assessed benefit, applicability, counterevidence, neighboring-grade rationale, German explanations and source-derived protocol facts. Record blind-to-final deltas.
5. Compare: mechanically compare values/sets; report confidence separately. Keep all eight rows, exclusions/holds and every disagreement. Attribute cause to packet gap, rule gap or lane deviation. Agreement is process repeatability, not efficacy accuracy.
6. Nick review: show the eight-row findings table, exact evidence limitations and unresolved admission/fit/protocol gates. Do not publish merely because both lanes agree. Review low/medium disputes and unsupported high claims explicitly.
7. Recalibrate: generalize actual traps, create a new semantic standard/prompt/runbook version, retain the old run and show replay deltas. Freeze separate unused holdout identities/metrics before holdout labels. Disclose any positive-coverage gap before lock.
8. Stop: after reviewed research and validation. Adapter, database integration and catalog additions follow the controlling plan and their own verification/approval gates.

Source preparation may be updated before freeze. Once frozen, changes produce new artifacts/receipts and clear amendment lineage. An inaccessible pivotal source is a hold, not favorable evidence. Do not generate a source hash for content that was not captured or a formula hash for only a marker excerpt.
