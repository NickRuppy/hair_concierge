# Bondbuilder researcher prompt v0.3

Use only explicit stage-authorized files. Complete method is immutable v0.1 base plus v0.3 overlay. No web/source fetches, plans/report, peer output, prior v0.1 lane transcripts/final labels, or further agents/reviewers. Write only your own named lane files, using apply_patch. Do not overwrite sealed output. Stage transitions require the orchestrator.

Stage A: both original and amended anonymous packets only. Return JSON `standard_version`, `lane_id`, `stage: A`, `input_receipt` (every file/hash), `no_web: true`, `recognition_incidents`, `records` (eight amended observations) and `control_records` (eight fresh original-input observations). Each row: `slot_id`, `markers` normalized ingredient array, `technology_candidates` family enum array, `formula_status`, `flags`, `classification_confidence` high/moderate/low string, `limitations`. For identical inputs own observation can be copied with explicit input equality note, not counted as an independent experiment. No trust/final boundary fields. Note brand recognition but do not import knowledge. Write `blind-records.json` and short `blind-notes.md`; stop for seal/unblinding.

Stage B: original named v0.1 evidence ONLY plus own sealed original-input observations. Apply v0.3 to old source facts, without importing new creator, science endpoint, protocol or identity amendments. Return JSON `standard_version`, `lane_id`, `stage: B`, `input_receipt`, `no_web: true`, `records` with eight control judgments. Row fields: `pilot_id`, `slot_id`, `boundary_status`, `technology_family`, `claim_trust_level`, `trust_basis`, `holds` (identity/boundary/claim_trust/protocol/fit arrays), `classification_confidence` high/moderate/low string, `confidence_by_property`, `assessed_benefit`, `supporting_source_ids`, `counterevidence`, `applicability_bridge`, `neighboring_grade_rationale`, `limitations`, `research_admission_candidate` boolean, `application_facts`, `concise_de` and `deeper_de`. Write `control-records.json` plus `control-notes.md`; stop before amended evidence.

Stage C: amended named evidence plus own sealed StageA/StageB. Same row shape, eight amended judgments. JSON metadata as above with `stage: C`; write `records.json` and `notes.md`. Do not revise the prior control after seeing new evidence.

Across B/C: compatible boundary/technology can remain finalized while trust is held; identity/formula conflicts hold target boundary/technology while blind marker clues remain recorded. Exact compatible No.3PLUS is the owner high anchor (`trust_basis: owner_anchor`); original No.3 is contextual, not a ninth row. Do not manufacture empirical proof. Other rows use research judgment or null. Medium uses the approved empirical or credible-technology-plus-sustained-informed-experience route; unknown active concentration alone is not a hold. Identify genuinely pivotal gaps, not every unavailable optional source. Commercial context is disclosed, not an automatic exclusion. Inaccessible video metadata is not an efficacy verdict. Softness/system benefits are not proof of molecular repair.

Research admission means source-version candidacy only; unresolved pack/catalog/fit/protocol remain separate readiness holds. No global readiness, efficacy ordering, price/potency rule, personal guarantee, or scientific certainty percentage. End each stage with no-web/read/incident/ambiguity receipt. The orchestrator compares/adjudicates; you do not review a peer or dispatch another reviewer.
