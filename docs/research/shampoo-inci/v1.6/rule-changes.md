# Rule changes: v1.6 vs v1.4

Baseline: `docs/research/shampoo-inci/v1.4/classification-standard.md` (SHA-256 `0f9f6a6d…928f24`, frozen). Target: `classification-standard.md` in this directory (locked v1.6, 2026-10-10, ruling R14). This ledger is the v1.6 candidate changelog (`plans/shampoo-v16/v1.6-candidate/changelog-vs-v1.4.md`) at lock, with its file references re-pointed to the locked package; its rows are unchanged. "v1.6 candidate" in a row means the rule as it was at that revision.

"Live value" means a `product_shampoo_specs` row (thickness, bucket, scalp route, cleansing intensity) that the projection could add, remove or change once v1.6 is locked and Production Light is re-pinned. Nothing in this candidate changes a live value by itself.

Sources: **v1.5** = Focus v1.5 overlay approved 2026-09-03; **H3** = holdout-v3 adjudication / operator clarification; **P** = new projection rules (this draft); **E** = editorial or enforcement of an existing v1.4 rule; **R2–R6** = Nick's rulings of 2026-10-07 in `data/research/shampoo-inci/v1.6/rulings-ledger.md` (snapshot of `plans/shampoo-v16/rulings.md` at R16); **R11**, **R12** = Nick's rulings of 2026-10-09 in the same ledger; **R14**, **R15**, **R16.1**–**R16.4** = Nick's rulings of 2026-10-10 in the same ledger; **round 2** = a clarification listed in `data/research/shampoo-inci/v1.6/calibration/round-2/round-2-report.md` (consensus uncertainties and remaining clarifications, from the round-2 lane `uncertainties`); **WM** = weight method integration (`docs/research/shampoo-inci/v1.4-draft/weight-potential-final-method.md`, one of the three sources the v1.4 README lists as consolidated into v1.4; Nick ruled 2026-10-09 to add it); **OA** = the v1.4-draft operational amendment and the v1.4 runbook's decision trace; **A n** / **B n** = round-1 ambiguity closed, lane A item n (counted in the order of `data/research/shampoo-inci/v1.6/calibration/round-1/lane-a-ambiguities.md`, 1–21) or lane B item n (`lane-b-ambiguities.md`, numbered 1–29).
