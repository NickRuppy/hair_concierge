## Failure handling and limits

The lock is `/tmp/test-audit-pruning-operator-lock`. On foreign/stale lock refusal, stop and inspect; these tools never delete a lock they do not own. Normal caught errors release only their token-owned lock. SIGKILL, power loss or a killed parent can leave an active fault and lock; inspect the intent/backup/receipt and current bytes before any manual restoration. Never overwrite concurrent differing source bytes. No broad reset, checkout, stash, process search/kill, Git write or automatic retry exists.

The helper uses actual filesystem Git metadata without spawning Git. Whole packed-refs changes can intentionally stop even when this task's target commit is stable. Main must resolve a legitimate metadata drift explicitly; a changed task commit, source/proposal/dependency pin, or mixed phase is never silently adopted. Runtime environment values are not recorded; mutation mode rejects known active harness/Node-option overrides before starting. The check path never reads environment files or imports application/test modules. TypeScript is loaded only as a parser.
