## 1. How the cohort was built

1. The round-5 script `build/freeze-cohort-r5.js` is run unchanged in a sandbox whose writes go to memory (it rebuilds rounds 4…1 the same way). Its 432 round-5 outputs were compared with `r5/` on disk: 431 byte-identical, 1 (`r5/FREEZE-NOTES.md`) identical after the superseded note added on top of it; the build stops on any other difference. Its 143 records are the base; no record is added or removed and every cohort role is kept.
2. Fixes P5-1…P5-3 are applied (section 3). No capture file is added and no captured value is edited.
3. Opaque ids: `sty-` + 10 hex of SHA-256(`styling-inci-v1.0-cohort-6/opaque-id/` + slug). No round-6 id equals a round-1…5 id (checked). The slug ↔ id map lives only in `r6/cohort.json`.
