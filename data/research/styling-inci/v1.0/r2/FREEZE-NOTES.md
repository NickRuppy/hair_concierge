# FREEZE-NOTES - Styling round-2 calibration cohort (styling-inci-v1.0-cohort-2)

Generated by `build/freeze-cohort-r2.js` (deterministic; re-run to reproduce every hash in `r2/artifact-manifest.json`). Frozen 2026-10-12. Standard `styling-inci-v0.2`, lexicon `styling-lexicon-v0.2`. Every number below is computed by the script. Nothing here is committed or locked, and nothing is classified (no route, subtype or hold level is assigned).

## 1. How the cohort was built

1. The round-1 script `build/freeze-cohort.js` is run unchanged in a sandbox whose writes go to memory. Its 324 outputs were compared with the round-1 files on disk: 324 of 324 byte-identical (the build stops on any difference). Its 107 records are the base.
2. Round-4 re-capture patches (`capture/recapture-r4.json`) and the v0.2 capture rules (P-4, P-6, RG-13) are applied (section 3).
3. The 32 new products of `capture/round2-new-r4.json` are frozen with the same record schema. Records that fail an evidence item are still frozen (they test the gate).
4. Opaque ids: `sty-` + 10 hex of SHA-256(`styling-inci-v1.0-cohort-2/opaque-id/` + slug). No round-2 id equals a round-1 id (checked). The slug ↔ id map (and the round-1 id) lives only in `r2/cohort.json` (`id_map`, `records[].source_slug`, `records[].history.round2.round1_sample_id`).
