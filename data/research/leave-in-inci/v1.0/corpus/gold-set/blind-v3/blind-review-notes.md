## 1. Method choices this lane had to invent

The standard does not decide these. They are stated so a diff can separate a method difference from a judgment difference.

- **MC-1 — directions tier.** The packet stamps C-tiers on `claims[]` but **not on `directions_of_use`**, which §2.4 and §7.13 both require. Convention adopted: German-language, pack-style directions for a German-market product whose brand owner has an identified C1/C2 German source ⇒ treated as C1/C2 (`directions_tier_basis: assumed_pack_or_C2, unstamped`). Directions available only in English from a non-German brand or retailer context ⇒ C5 ⇒ **ROLE `unknown`, `usage_role: []`**. This convention alone empties `usage_role` on four records (Curlsmith, EVO, Olaplex — and it would have on Maria Nila had it stayed in category).
- **MC-2 — which observations "established COND" (§10.2.1).** Where several routes could establish COND, the establishing set is taken to be the **minimal set that clears the anchor, choosing the non-film route first** (cationic and/or emollient), so a dedicated persistent-silicone or cationic-polymer film system stays available as the *additional* observation. Adopted because §10.2.1's own first bullet requires `smoothing` to be **reachable** for a dedicated silicone film system; the opposite choice makes `smoothing` unreachable for every COND-`high` product.
- **MC-3 — missing §18 strings.** No string is emitted for `EXPO = aromatic_or_allergen_exposure`, for `scalp_application_fit = conditional`, or for a shake instruction on a non-`two_phase` product. §18 has no row for any of them.
- **MC-4 — the §18 "HUM humectant counter-signal" row is not emitted.** §10.1.1/G14 and §18's own register rule both forbid a user-facing string emitted by a counter-signal.
- **MC-5 — no LAYER string on any record.** §8.4 says "emit at most one" and never says when.

## 4. Residual ambiguities in v0.3

Numbered for citation. Items marked **NEW** are not, as far as this lane can tell from the v0.3 text alone, already listed in §17 or in §21.2's "deliberately not changed" table.

- **AMB-01 — §4 makes every derived fit invalid in a product-only record. NEW.** §4: "A derived fit without both `derived_from` **and** `profile_fact_ids` is invalid." A blind product record has no user profile facts to reference, so `hair_thickness_fit`, `damage_fit`, `texture_fit`, `scalp_application_fit` and DOSE are all formally invalid as written. Either the field is optional for product-side records or its meaning needs defining. This lane omits it rather than fabricating ids.
- **AMB-02 — the packet stamps no C-tier on `directions_of_use`. NEW (adjacent to §17.23 but distinct).** §2.4's v0.3 packet requirement says "a packet must stamp **every source** with this standard's own C1–C5 tier", and §7.13 rule 1 makes ROLE readable only from C1/C2 directions — yet the round-3 packet carries tiers on `claims[]` only. Every ROLE value in this review therefore rests on MC-1 rather than on a stamp. This is the same class of defect the v0.3 packet fix list closed for claims, left open for directions.
- **AMB-03 — §10.2.1 does not say how to choose the set that "established COND". NEW.** When COND `high` is reached by "an LGN pair plus **at least one** further route" and two or three further routes are available, which one is spent decides whether `smoothing` qualifies. §10.2.1 states the outcome in both directions but gives no selection rule. Five records in this set turn on it.
- **AMB-04 — §3.1.1 clause 1 vs mandatory limit 3.** v0.3 makes rank the single deterministic prong for *every* §7 anchor and forbids raising a value rank does not support (clause 2), while the unamended limit 3 instructs the reviewer to hold COND and WT at the architecture-supported level under a very early marker. §21.2 records the marker's **variance** as carried open (ref A17 / blind A4, §17.18) but not this **direct rule contradiction**. Decisive on slot 9.
- **AMB-05 — §10.2's `repair` row contradicts §10.2 principle 4, §9 constraint 3 and G2. NEW.** The row qualifies `repair` on "protein/silane actives in the product's C1/C2 marketing position", i.e. positioning creating a route — which principle 4 forbids in the same section, §9 constraint 3 forbids for the same evidence shape ("a product sold entirely on keratin repair whose only protein is a plain hydrolysate is `moisture` or `unknown`"), and G2 forbids as an E0 claim setting a user-facing purpose. It also splits `focus` from `damage_fit`, which reads R2 only. Slot 8 ends with `focus: repair` and `highly_damaged: conditional`.
- **AMB-06 — §18 string gaps. NEW.** No string exists for (a) `EXPO = aromatic_or_allergen_exposure`, which is the most common EXPO value in the set — nine of eleven profiled records; (b) `scalp_application_fit = conditional`, the value the v0.3 narrowing was written to make reachable (slot 2 reaches it and says nothing to the user); (c) a shake instruction on a product whose FORM is not `two_phase` (slot 8's pack says „Vor Gebrauch schütteln!“ and the caution is suppressed).
- **AMB-07 — §18's "HUM humectant counter-signal" row contradicts §10.1.1, G14 and §18's own register rule. NEW.** A string emitted by a counter-signal is exactly what trace containment forbids, and §18's v0.2 note repeats the ban three rows below the offending row.
- **AMB-08 — §8.4 defines no emission trigger for the LAYER caution. NEW.** "Emit at most one German caution string" with no condition attached means two lanes cannot agree on whether it appears.
- **AMB-09 — `claims_status: none_found_at_C1_C2` conflates two states the standard says must not be conflated.** §2.4 rule 2 is explicit that "not captured" and "does not exist" are different states, yet the packet uses one status value for both — slot 4 (a C2 source was located and states nothing) and slot 6 (no C1/C2 source exists at all) carry the same stamp, while `claim_authority_gap` routing should differ between them. Resolved here from the free-text `claims_search_note`, which is not machine-comparable.
- **AMB-10 — `scalp_application_fit = avoid`'s "oil-led two-phase load" trigger has no threshold. NEW.** It fired on both alverde records. Any two-phase product carries an oil phase by design (FS-18), so the trigger arguably fires on every `two_phase` record, making the most restrictive scalp value automatic for the form — structurally the same overshoot v0.3 change 12 just removed for fragrance flags.
- **AMB-11 — no rule for a protein/silane active named among several in a multi-benefit C1/C2 description.** Slot 1's C2 text names „pflanzliches Keratin“ among four actives in a 7-in-1 description. §10.2's repair limb says "named … as what the product is *for*"; whether a multi-benefit list satisfies that is undecided. Read here as *not* satisfying it — the opposite reading of the same rule that fires on slot 8.
- **AMB-12 — `presentation_form` is required but never specified.** §7.1 and §10.1 say the marketing form word is preserved as `presentation_form` metadata; no vocabulary, no source rule and no place in the §10 profile block are given.
- **AMB-13 — §14 has no review trigger for `scalp_application_fit = avoid`,** the most restrictive value in the model, while `suitable_if_evidenced` routes "without exception". Four records reach `avoid` here.
- **AMB-14 — whether EXPO `no_listed_fragrance_signal` is itself "a fragrance-free or hypoallergenic implication" for §14.** Routed to review on slot 11 (a C2 „Ohne Parfüm“ badge exists) and not on slot 13 (no claim), which is a defensible line the standard does not draw.

**Confirmed still open, already recorded in v0.3, and observed at scale this round:** §17.16 / §17.5 — the SLIP bias qualifier returned `unknown` on **7 of 11** profiled records. §17.18 — marker variance: rank 3/24 (slot 9), rank 6/25 (slot 5), rank 14/16 (slot 4), rank 38/42 (slot 6); it decided values in all four. §17.19 — Polyacrylamide's L5 placement was decisive on two records (slots 5 and 9) as the emulsifier-system reading. §17.20 — `curl_definition_focus` still has no value vocabulary, so no value was emitted anywhere. §17.21 — Isopropyl Alcohol appeared twice (slots 6, 10) outside the alcohol enumeration. §17.22 — `care_direction` returned `moisture` for film-led architectures on slots 13 and 8. §17.23 — captured-but-below-authority directions emptied `usage_role` on three records. §17.24 — the excluded records emit no §7 dimensions and say so, because the standard does not say which they may carry.
